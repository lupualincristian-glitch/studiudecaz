01 — FUNDAMENTE
⚙️ Ce este GIT?

Git este un sistem distribuit de control al versiunilor care urmărește fiecare modificare a codului sursă, permițând colaborarea mai multor dezvoltatori fără conflicte.

$ git log --oneline
a3f8c12 feat: adaugă autentificare
b7e1d09 fix: rezolvă bug login
🐙 Ce este GitHub?

GitHub este o platformă cloud de găzduire cu funcționalități de colaborare: pull requests, code review, issues și automatizare CI/CD.

Pull Requests Issues Codespaces Copilot Projects
02 — FLUXUL DE LUCRU ÎN ECHIPĂ
1
🍴 Fork & Clone

Fiecare membru creează o copie locală. Modificările personale nu afectează codul principal până la aprobare.

$ git clone https://github.com/org/proiect.git
2
🌿 Branch — Izolarea Funcționalităților

Fiecare feature sau bugfix se dezvoltă pe un branch separat. Ramura principală (main) rămâne stabilă.

3
💬 Pull Request & Code Review

Modificările sunt revizuite de colegi înainte de integrare pentru a asigura calitatea codului.

4
🔀 Merge & Deploy

După aprobare, codul este integrat în ramura principală și livrat automat.

$ git merge feature/login --no-ff
03 — DE CE CONTEAZĂ
🔒
Siguranța Codului

Nicio modificare nu se pierde. Istoricul complet permite revenirea la versiuni anterioare.

⚡
Productivitate Sporită

Zeci de developeri pot lucra simultan fără să blocheze activitatea celorlalți.

👁️
Transparență Totală

Fiecare commit înregistrează cine și ce a modificat în cadrul echipei.

04 — COMENZI ESENȚIALE
terminal -- bash
$ git init
Inițializează un repository nou
$ git clone <url>
Clonează un repository existent
$ git add .
Adaugă toate modificările în staging
$ git commit -m "mesaj"
Salvează modificările efectuate
$ git push origin main
Trimite codul pe GitHub
$ git pull origin main
Actualizează codul local de pe server

07 — EXTENSII ȘI ECOSISTEM GITHUB
💻
GitHub Codespaces

Mediu de dezvoltare complet (VS Code) accesibil direct în browser. Permite echipei să înceapă scrierea de cod instant, fără configurări locale complexe.

🤖
GitHub Copilot

Asistent virtual bazat pe AI ce oferă sugestii de cod în timp real, accelerează scrierea funcțiilor și ajută la explicarea codului existent.

📋
GitHub Projects

Tablouri de bord Kanban și grafice de planificare integrated direct cu depozitul de cod pentru gestionarea sarcinilor și a sprinturilor echipei.

💬
GitHub Discussions

Spațiu dedicat conversațiilor, ideilor noi și întrebărilor comunității sau echipei, păstrând secțiunea de Issues curată doar pentru bug-uri.

🔀
All Pull Requests

Centralizează toate propunerile de modificare din proiectele echipei, facilitând procesul de Code Review și aprobare rapidă a schimbărilor.

🎯
All Issues

Urmărirea centralizată a tuturor problemelor, erorilor și cerințelor de funcționalități noi raportate de colegi sau utilizatori.
